# HR-Analytics-Dashboard
HR_Analytics_Dashboard

📊 Human Resources Analytics Dashboard

Overview

The HR Analytics Dashboard is an interactive Business Intelligence project developed using Tableau to analyze employee data and generate meaningful insights into workforce demographics, departments, salary, education, performance, employment status, and geographic distribution.

The project transforms raw HR data into interactive visualizations and dashboards that help organizations understand their workforce, monitor employee trends, and support data-driven decision-making.

The analysis covers the complete data analytics workflow, including data preparation, exploratory analysis, visualization, dashboard development, and business insight generation.
